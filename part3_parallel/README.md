# Часть 3. Многопоточная и многопроцессорная обработка данных

Конвейер producer-consumer: потоки читают файлы, процессы аугментируют
изображения, результат сравнивается с последовательной версией.

## Структура

| Файл | Назначение |
|------|------------|
| `app/producer_consumer.py` | очереди, потоки-потребители, пул процессов, счётчик под `threading.Lock` |
| `app/augment.py` | поворот, отражение, гауссов шум, пакетная аугментация |
| `app/performance.py` | замеры, сравнение и запись `performance_report.json` |
| `app/cli.py` | командная строка для запуска конвейера |

## Запуск

```bash
cd part3_parallel
python -m app.cli --path ../data/input/aug_images --ext .png \
    --workers 4 --processes 4 \
    --output augmented.npy --report performance_report.json
```

## Схема работы

1. Поток-производитель обходит каталог и кладёт пути в `queue.Queue`.
2. Четыре потока-потребителя читают изображения, нумеруют их под
   `threading.Lock` и передают массивы во вторую очередь.
3. Главный поток собирает пачки по 8 изображений и отправляет их в пул
   процессов через `multiprocessing.Pool.apply_async` с callback.
4. Callback складывает результаты по индексам, поэтому порядок файлов
   сохраняется, несмотря на параллельную обработку.
5. После обработки потоки и пул закрываются: маркеры `SENTINEL`
   завершают потребителей, `Pool.close()` и `Pool.join()` - процессы.

Изображения между процессами передаются в `uint8`, а не в `float32`:
это вчетверо уменьшает объём данных в каналах межпроцессного обмена.

## Отчёт о производительности

`performance_report.json` содержит:

- окружение: версия Python, платформа, число ядер;
- параметры набора: каталог, число файлов, форму массива;
- время последовательной и параллельной обработки;
- ускорение по полному времени и по времени обработки без создания пула;
- отдельный замер чистой аугментации без чтения файлов.

## Переменные окружения

| Переменная | По умолчанию | Смысл |
|------------|--------------|-------|
| `NN_AUG_PATH` | `data/input/aug_images` | каталог с изображениями |
| `NN_OUTPUT_DIR` | `data/output` | каталог результатов |
| `NN_WORKERS` | `4` | число потоков чтения |
| `NN_PROCESSES` | `4` | число процессов аугментации |
| `NN_LOG_LEVEL` | `INFO` | уровень логирования |
