# Часть 1. Объектно-ориентированная реализация многослойного перцептрона

Небольшая библиотека на чистом NumPy и консольное меню к ней.

## Структура

| Файл | Назначение |
|------|------------|
| `app/models.py` | класс `NeuralNetwork`: прямой проход, обратный проход, обучение, сохранение весов |
| `app/manager.py` | класс `DatasetManager`: чтение CSV, разбиение на train/test, нормализация |
| `app/exceptions.py` | собственные исключения приложения |
| `app/utils.py` | разбор пользовательского ввода и форматирование вывода |
| `app/main.py` | консольное меню (7 пунктов) |

## Запуск

```bash
cd part1_mlp
python -m app.main
```

Данные по умолчанию берутся из `../data/input/mlp_dataset.csv`, веса
сохраняются в `../data/output/part1_weights.json`, график ошибки -
в `../logs/part1_loss.png`.

## Переменные окружения

| Переменная | Значение по умолчанию | Смысл |
|------------|----------------------|-------|
| `NN_DATA_PATH` | `data/input/mlp_dataset.csv` | путь к CSV с данными |
| `NN_TEST_RATIO` | `0.2` | доля тестовой выборки |
| `NN_WEIGHTS_PATH` | `data/output/part1_weights.json` | файл для весов |
| `NN_PLOT_PATH` | `logs/part1_loss.png` | файл для графика ошибки |
| `NN_SEED` | `42` | зерно инициализации весов |

## Формат CSV

Первая строка - заголовки, последний столбец - целевая переменная
(0/1 для классификации), остальные столбцы - числовые признаки.

## Что умеет сеть

- произвольное число слоёв (минимум один скрытый);
- функции активации `sigmoid`, `relu`, `tanh`, `linear`;
- обучение мини-батчами с сохранением истории ошибки;
- сохранение и загрузка архитектуры и весов в JSON;
- оценка качества на тестовой выборке.
